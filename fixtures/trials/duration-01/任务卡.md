# duration-01：开发与测试任务卡

本文件是四项任务的执行要求。工作目录统一为项目根目录，不是本文件所在目录。按委托中的taskId读取对应任务；不要只凭标题猜任务。

## 本次需求

编写一个无依赖的JavaScript ESM模块，导出 `parseDuration(input)`，将“分钟:秒”解析为总秒数。模块路径：`.scheduler/trials/duration-01/src/parse-duration.mjs`。

规则只有以下几条：

- 只接受原始string；其他类型直接返回null，不抛异常。
- 使用JavaScript的String.trim规则去掉首尾空白，内部空白不允许。
- 去掉首尾空白后，格式严格为ASCII数字`[0-9]{1,3}:[0-9]{2}`。
- 分钟范围0—999，秒范围00—59；返回分钟乘60加秒。允许前导零。
- 无效格式或范围返回null。模块不得在导入时执行CLI、打印日志或读取文件。

| 输入 | 预期结果 |
|---|---:|
| `"0:00"` | 0 |
| `"1:02"` | 62 |
| `"12:34"` | 754 |
| `" 005:07\n"` | 307 |
| `"999:59"` | 59999 |
| `""`、`"1:2"`、`"1:60"`、`"1000:00"` | null |
| `"-1:00"`、`"1.5:00"`、`"1 :02"`、`"1:02x"`、`"１２:３４"` | null |
| null、undefined、number、boolean、数组、对象 | null |

这些规则是测试依据。开发与测试成员遇到歧义向Lead报告，不自行更改输入范围。

## A2：实现（开发）

前置A1完成。读取实际contract，创建`src/parse-duration.mjs`，实现named export `parseDuration`。只使用Node／JavaScript已有能力，不安装依赖、不修改项目package.json或调度器源码。

检查导出可导入、语法正常以及关键示例。简单检查可以直接在控制台运行，不额外写入测试成员的文件。按实际结果提交completed或failed，产物`implementation`引用实现文件。

## B1：独立测试（测试）

前置contract已交付。只读contract和本任务卡，不阅读实现；使用Node内置`node:test`、`node:assert/strict`创建`tests/parse-duration.test.mjs`，从`../src/parse-duration.mjs`导入函数。

测试覆盖有效边界、前导零、首尾空白、无效格式／秒范围以及非字符串输入。实现可能还不存在，本项以测试文件编写完成为交付，不提前运行联合测试。

提交completed，产物`tests`引用测试文件。不得修改实现，也不得因担心测试失败而放宽预期。

## B2：联合运行与证据（测试）

前置A2与B1完成。只读实现和测试，运行：

```powershell
node --test .scheduler/trials/duration-01/tests/parse-duration.test.mjs
```

先创建`evidence`目录，实际运行时保存完整stdout、stderr和退出码，再写简短结果。目录内至少包含：

- `stdout.txt`、`stderr.txt`：本次实际命令的原始输出。
- `exit-code.txt`：紧接该Node进程结束取得的实际退出码。
- `test-report.md`：命令、开始／结束时间、Node版本、通过／失败数和错误摘要；产物`test-report`引用此文件。

可使用下述PowerShell命令保存证据；退出码要在执行其他外部命令前取出：

```powershell
$evidenceDir = '.scheduler/trials/duration-01/evidence'
New-Item -ItemType Directory -Path $evidenceDir -Force | Out-Null
node --version | Set-Content -LiteralPath "$evidenceDir/node-version.txt" -Encoding utf8
Get-Date -Format o | Set-Content -LiteralPath "$evidenceDir/started-at.txt" -Encoding utf8
node --test .scheduler/trials/duration-01/tests/parse-duration.test.mjs 1> "$evidenceDir/stdout.txt" 2> "$evidenceDir/stderr.txt"
$trialExitCode = $LASTEXITCODE
$trialExitCode | Set-Content -LiteralPath "$evidenceDir/exit-code.txt" -Encoding utf8
Get-Date -Format o | Set-Content -LiteralPath "$evidenceDir/ended-at.txt" -Encoding utf8
```

退出码0且测试确实执行时提交completed；否则提交failed并引用错误报告。不得以“文件已生成”或一句“通过”替代命令证据，也不修改实现／测试来掩盖失败。首轮到此结束，后续修复另由Lead与用户安排。
